# Turing Bloom

> 原作：**Reaction Diffusion**  
> 作者：**Amanda Ghassaei**  
> 原始演示：https://apps.amandaghassaei.com/gpu-io/examples/reaction-diffusion/  
> 原始源码：https://github.com/amandaghassaei/gpu-io/tree/main/examples/reaction-diffusion  
> 许可证：MIT

Turing Bloom 是面向 AlterU 手机信息流改造的反应扩散视觉玩具。它保留原作
Gray–Scott 方程、K/F 参数地图、GPU ping-pong 计算、单指播种和双指视图变换，
并增加竖屏构图、真实效果幽灵手指、25 秒培养结算和离屏暂停。

## Development

```bash
npm install
npm run dev
npm run build
```

第三方完整许可见 `public/THIRD_PARTY_NOTICES.txt`。
