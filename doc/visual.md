# Visual Bible

## 1. 核心命题

“一张正在决定自己物种的活体地图。”玩家记住的不是按钮，而是同一屏里从雪花颗粒过渡到豹斑、珊瑚和迷宫的连续形态。

## 2. 构图与镜头

全屏无边框正投影，纹样铺满 100dvh。左上标题与右上计时占据安全区，视作科学标本页的页眉；中央和拇指常经过的下半屏不放持久控件。结算为窄幅文字层，让完成纹样继续可见。

## 3. 色彩

- `Carbon #07090C`：背景与 Chemical A。
- `Bone #EEF0E8`：Chemical B 主体、标题与关键数值。
- `Mineral #9BA69E`：说明、署名和非关键刻度。
- `Spore #D9FF72`：仅用于交互瞬间的细微强调，不覆盖模拟颜色。

## 4. 字体

标题采用 Arial Narrow / Helvetica Neue Condensed / Noto Sans SC，900 字重、紧行距、负字距。科学标记采用等宽字体 SFMono-Regular / Menlo / Noto Sans Mono CJK SC。正文中文最低 16 px；微型非交互标记可为 9–11 px。

## 5. 形状、材质与光

模拟本身保持无光照的二维化学浓度图，禁止加玻璃、霓虹描边或三维浮雕。UI 只使用 1 px 线、直角或极小圆角；不使用大圆角卡片。

## 6. 素材规则

唯一核心素材由 Gray–Scott shader 实时生成。AlterU 水印使用共享单色白色 SVG。幽灵手指使用 Google Material `touch_app` 轮廓。无需头像、用户名或生成图片。

## 7. UI 与图标

重置使用同一套 24×24、1.5 px 描边 SVG。所有触控目标至少 44×44 px。隐藏式双指操作允许一行文字说明；单指操作只由幽灵手指与真实效果演示。

## 8. 动效与 VFX

幽灵手指 3.6 秒沿短弧线拖动，轨迹位置同步向模拟场注入真实种子，不能只有手指空动。输入在同一帧写入场。结算文字在 420 ms 内淡入，模拟仍在背景缓慢演化。减少动态模式下停用 UI 循环动画，但保留化学模拟作为玩法本身。

## 9. 参照物转译

直接沿用 Amanda Ghassaei 原作的 K/F 空间映射、Gray–Scott 方程、随机初始态、单指写入、双指平移缩放与 GPU ping-pong 计算。AlterU 版本只调整竖屏构图、资源暂停策略、引导和 25 秒轻闭环。

## 10. 反模式

禁止彩虹渐变、荧光玻璃面板、设备外框、视频播放按钮、海报式开场遮罩、长篇操作说明、无效果的幽灵手指、与反应扩散无关的粒子爆炸，以及为了个性化强行塞入头像或用户名。

## 11. 垂直切片验收

- 390×844 与 320×568 均能看到至少三种连续纹样区。
- 左上标题、右上计时、底部署名不与平台安全区冲突。
- 幽灵手指移动处必须同步出现可见化学扰动，玩家触摸后立即消失。
- 单指绘制、双指平移缩放、25 秒结算和重开均可达。
- 页面不可见或 iframe 低于 35% 可见时停止 requestAnimationFrame 推进。
