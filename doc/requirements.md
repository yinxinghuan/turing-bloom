# Requirements

## 1. Overview

一件没有局时与终点的触屏反应扩散视觉玩具：玩家可以在整屏活体参数地图上持续划入化学种子，停下来观察，也可以随时再次介入，让斑点、迷宫与细胞纹样不断变形。

## 2. Visual Design

画面以全屏 GPU 生成纹样为唯一主角，保留原作参数地图同时呈现多种形态的视觉奇观。标题占左上安全区，右上只用安静的活体状态标记说明这是一片持续开放的培养场；不显示进度、分数或结算遮罩。

## 3. Game Mechanics

- 初始 K 范围为 `0.050–0.066`，F 范围为 `0.016–0.044`，扩散率 A/B 分别为 `0.2097 / 0.105`。
- GPU 每个可见动画帧推进 8 次 Gray–Scott 反应扩散；430 px 及以下窄屏推进 6 次。
- 单指按下即写入第一个种子，随后每次移动都以 34 CSS px 直径写入 A/B=`0.5 / 0.5` 的种子。
- 松手只表示停止播种，模拟继续生长；再次触摸可在任意时刻继续介入，没有不可交互阶段。
- 触点按 3×3 参数网格记录已探索区域，首次进入每个区域时播放一枚轻微音调；该记录不触发进度、胜负或结束。
- 培养场无限运行，只有玩家主动按下重置按钮才生成新的随机初始状态并恢复原始参数范围。
- 进入后台或可见比例低于 35% 时暂停 GPU 循环，避免列表预加载消耗资源。

## 4. Controls

- 单指按下并拖动：种入化学扰动；首次拖动关闭幽灵手指演示。
- 双指拖动：平移 K/F 参数范围。
- 双指开合：围绕两指中心缩放 K/F 参数范围。
- 重置按钮：由玩家主动结束当前观察，恢复原始参数范围并生成新的随机初始状态。

## 5. Win / Lose Conditions

本作没有胜利、失败、倒计时、成熟度或自动结算。培养场不会自行结束，玩家可以无限观察与介入；只有重置会开始一片新培养场。若 WebGL 初始化失败，显示错误与重试入口。

## 6. Sound Effects

- 第一次种入：正弦波 92→115 Hz，时长 180 ms，峰值音量 0.018。
- 新参数区域首次被触及：正弦波从 `240 + 区域编号 × 35` Hz 上滑 1.25 倍，时长 90 ms，音量 0.010。
- 重置不播放胜利或失败音，只通过新随机纹样和按钮按压反馈确认换场，避免制造“完成一局”的暗示。
