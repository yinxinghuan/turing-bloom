# Requirements

## 1. Overview

一件 25 秒的触屏反应扩散视觉玩具：玩家在整屏活体参数地图上划出化学种子，看不同区域长出斑点、迷宫与细胞纹样，最终得到一次生命力结算。

## 2. Visual Design

画面以全屏 GPU 生成纹样为唯一主角，保留原作参数地图同时呈现多种形态的视觉奇观。标题占左上安全区，计时位于右上，常规 UI 使用极细线与克制的冷白色；结算只覆盖中央小块区域，不遮蔽培养完成的纹样。无需头像或用户名素材，因为原效果并不基于可替换的图片或文字。

## 3. Game Mechanics

- 初始 K 范围为 `0.050–0.066`，F 范围为 `0.016–0.044`，扩散率 A/B 分别为 `0.2097 / 0.105`。
- GPU 每个可见动画帧推进 8 次 Gray–Scott 反应扩散；430 px 及以下窄屏推进 6 次。
- 第一次单指移动开始 25 秒培养；触点以 34 CSS px 直径写入 A/B=`0.5 / 0.5` 的种子。
- 每次移动累计轨迹距离，最多计 1600 px；触点按 3×3 参数网格记录区域多样性，最多 9 区。
- 生命力分数为 `min(999, round(轨迹距离 × 0.32 + 不同区域数 × 62))`。
- 进入后台、离开可视区域或尚未进入视口时暂停 GPU 循环与倒计时，避免列表预加载消耗前台游戏资源。

## 4. Controls

- 单指按下并拖动：种入化学扰动；首次拖动自动开始计时并关闭幽灵手指演示。
- 双指拖动：平移 K/F 参数范围。
- 双指开合：围绕两指中心缩放 K/F 参数范围。
- 重置按钮：恢复原始参数范围与随机初始状态。

## 5. Win / Lose Conditions

本作没有失败。培养开始 25 秒后进入结算，显示三位生命力分数与“再培养一次”按钮；重新开始立即恢复参数地图。若 WebGL 初始化失败，显示错误与重试入口。

## 6. Sound Effects

- 第一次种入：正弦波 92→115 Hz，时长 180 ms，峰值音量 0.018。
- 新参数区域首次被触及：正弦波从 `240 + 区域编号 × 35` Hz 上滑 1.25 倍，时长 90 ms，音量 0.010。
- 培养结束：三枚正弦波 330/440/660 Hz，分别延迟 0/90/180 ms，单枚 260 ms，音量 0.014。
- 音频必须由首次用户操作解锁；静音或 AudioContext 失败不影响游戏。
