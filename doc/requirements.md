# Requirements

## 1. Overview

一件自定节奏的触屏反应扩散视觉玩具：玩家在整屏活体参数地图上划出化学种子，让斑点、迷宫与细胞纹样达到成熟并生成一种标本名称。

## 2. Visual Design

画面以全屏 GPU 生成纹样为唯一主角，保留原作参数地图同时呈现多种形态的视觉奇观。标题占左上安全区，右上只显示由玩家播种行为推进的成熟度；结算只覆盖中央小块区域，不遮蔽培养完成的纹样。

## 3. Game Mechanics

- 初始 K 范围为 `0.050–0.066`，F 范围为 `0.016–0.044`，扩散率 A/B 分别为 `0.2097 / 0.105`。
- GPU 每个可见动画帧推进 8 次 Gray–Scott 反应扩散；430 px 及以下窄屏推进 6 次。
- 第一次单指移动开始培养；触点以 34 CSS px 直径写入 A/B=`0.5 / 0.5` 的种子。
- 每次移动累计轨迹距离，最多计 1600 px；触点按 3×3 参数网格记录区域多样性，最多 9 区。
- 成熟度为 `min(100, round(轨迹距离 × 0.12 + 不同区域数 × 12))`，只随有效播种增加。
- 成熟度达到 100 且全部手指离开 1.8 秒后完成培养；继续触摸会取消等待并允许调整纹样。
- 标本名称按区域数和轨迹长度分为 `CELLULAR / CORAL / LABYRINTH` 三类。
- 进入后台或可见比例低于 35% 时暂停 GPU 循环，避免列表预加载消耗资源。

## 4. Controls

- 单指按下并拖动：种入化学扰动；首次拖动关闭幽灵手指演示。
- 双指拖动：平移 K/F 参数范围。
- 双指开合：围绕两指中心缩放 K/F 参数范围。
- 重置按钮：恢复原始参数范围与随机初始状态。

## 5. Win / Lose Conditions

本作没有失败，也没有倒计时。成熟度达到 100 并静置 1.8 秒后显示标本类型与“再培养一次”按钮；重新开始立即恢复参数地图。若 WebGL 初始化失败，显示错误与重试入口。

## 6. Sound Effects

- 第一次种入：正弦波 92→115 Hz，时长 180 ms，峰值音量 0.018。
- 新参数区域首次被触及：正弦波从 `240 + 区域编号 × 35` Hz 上滑 1.25 倍，时长 90 ms，音量 0.010。
- 成熟度达到 100：正弦波 260 Hz，120 ms，音量 0.008。
- 标本定型：330/440/660 Hz 三枚正弦波，延迟 0/90/180 ms，单枚 260 ms，音量 0.014。
